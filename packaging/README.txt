zopana · Windows x64 自用便携版

启动
1. 在 Windows 11 x64 上解压整个 ZIP，保留 zopana-windows-x64 中的所有文件和子目录。
2. 双击 zopana.exe。“打开文件”或 Ctrl+O 选择一段本地视频。播放器使用 Windows 的当前音频输出设备。
3. 点击“暂停”。默认的“缩放拖动”模式下，在视频区把指针指向细节，上滚放大，按住左键拖动画面。
4. 在顶栏切到“常规播放”，在视频区上滚一格将音量增加 5 个百分点。单击等待系统双击间隔后切换播放，双击切换全屏。Ctrl+滚轮临时缩放。底栏的进度和音量滑块位于同一行，点击扬声器切换静音。
5. 视频区 S 停止、Space 重播，M 静音，方向键定位或调音量，V 切换模式，+/− 缩放（含数字小键盘），R 恢复适窗。Ctrl+G 输入跳转时间，F1 查看随当前绑定更新的完整快捷键帮助。
6. 右上角提供全屏、最小化、最大化／还原和关闭。F11、视频区 Enter（含数字小键盘）或双击画面也可切换全屏。全屏顶栏和底栏在闲置 2.5 秒后隐藏，移到对应边缘或用键盘操作可唤出。Esc 一次处理一层，退出全屏时恢复进入前的窗口状态。
7. 打开支持多选替换列表；Ctrl+Shift+O 添加，视频区 Ctrl+拖放追加，列表区域按插入线放置。添加文件夹后台扫描一层目录，可取消。可向已加载媒体拖入 SRT/ASS/SSA/VTT 字幕。
8. 按 P 或点击列表按钮切换队列显隐。列表标题区可切换浮动窗口，浮动列表可以单独移动和调整大小，与主窗口共用一个任务栏项目。主窗口最小化和恢复时，已展开的浮动列表随之隐藏和显示。列表中按 Ctrl+W 或点击关闭可收起列表。
9. 视频区和进度条共用三档定位：←/→ 默认 5 秒，Shift+←/→ 默认 30 秒，Ctrl+←/→ 默认 60 秒。底栏后退／前进左键按小步定位，右键切项。视频区 PageUp/PageDown 切项。列表中按 Enter 或双击播放，Delete 移除，Ctrl+方向键上下重排。
10. J 切音轨，H 显隐字幕，K 切字幕轨，Ctrl+L 加载外挂字幕。同目录自动匹配同基名及语言后缀字幕；字幕随画面缩放，放大后可能裁切，R 恢复适窗。音频/字幕菜单提供延迟数值及归零，字幕还可调整字体缩放。
11. [ / ] 调整倍速，Backspace 恢复 1×。播放菜单提供速度预设和保持音调。D 暂停并向前一帧，A/B 设置至少相隔 0.5 秒的区间循环，Ctrl+B 清除；定位到区间外自动清除。
12. Ctrl+S 保存采用播放方向、校正像素比例的完整画面，无字幕或取景裁剪。Ctrl+Shift+S 保存当前取景（含可见字幕和黑边）。两者均无应用提示，后台写入 PNG，默认保存在系统图片目录的 zopana 子目录。I 查看媒体信息；T 只置顶主窗口。
13. 播放菜单提供不循环、单个循环、全部循环，随机播放可独立开启。「列表排序」可按文件属性、时长、标题等排序，也可反转、打乱或恢复添加顺序。排序不会换片；后台读取时可取消。重启只恢复排序条件，队列为空。
14. 播放菜单的「跳略播放」可设置每部媒体通用的片头、片尾跳略秒数，默认关闭。视频区按 ' 打开设置、Shift+' 切换总开关。新开或重播从片头后的时间开始；自动跳过片尾时按循环和随机策略接续。有效断点优先，手动定位到片尾可继续观看。
15. 视频区 Alt+K 顺时针旋转 90°，Alt+Shift+K 逆时针，Ctrl+Alt+K 复位额外角度。1–5 分别应用 50%、100%、150%、200% 或适合工作区。100% 按物理像素计算；屏幕放不下时会限幅。R 只恢复适窗取景。
16. 按 F5 打开设置，可改定位步长、截图目录、语言、断点策略、取景、窗口大小和快捷键。应用或确定后才生效，取消会丢弃未应用的草稿。快捷键冲突可确认替换，F11/Enter、Esc、Tab 和系统保留键受保护。
17. 播放历史默认关闭。启用后最多保存 50 项。有效断点须播放超过 30 秒且距结尾超过 30 秒；默认暂停询问继续／从头，8 秒未选则使用片头设置。文件变化会使旧断点失效。暂停、换片和退出时会补存；自然结束或自动跳过片尾会清除该断点。
18. 倍速、音调、音量、静音、字幕设置、鼠标模式、旋转、取景和窗口布局都会记住。关闭或清除历史不影响这些偏好。便携版也把设置和历史保存在当前 Windows 用户的配置目录中。

便携包随附 Qt 运行库、Windows 平台插件、OpenGL 软件后备、libmpv 和程序本地的 Microsoft Visual C++ x64 运行库。上述文件可与程序一起移动。若运行库文件被移走，重新完整解压。使用系统级运行库的管理员可安装微软的 Visual C++ v14 x64 Redistributable：
https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist

文件校验
在打包输出目录的 PowerShell 中运行 Get-FileHash -Algorithm SHA256 .\zopana-windows-x64.zip，核对同目录中的 zopana-windows-x64.zip.sha256。
可以解压到含中文和空格的目录。完整解压后再运行 zopana.exe，并随程序移动整个目录。
