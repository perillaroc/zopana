# 截图与设置

## 保存截图与查看媒体信息

| 操作 | 结果 |
| --- | --- |
| **Ctrl+S** | 保存无字幕的原始画面。 |
| **Ctrl+Shift+S** | 保存包含字幕和黑边的当前取景，排除应用 OSD。 |
| **I** | 打开媒体信息，查看分辨率等实际信息，也可通过「视图 → 媒体信息」打开。 |
| **T** | 切换主窗口置顶。 |

截图在后台写入系统图片目录的 `zopana` 子目录，格式为 PNG，文件名自动避开已有文件。保存成功后会显示路径和「打开文件夹」。按 **F5** 打开设置可更改保存目录。

## 设置定位步长、语言偏好和快捷键 {#seek-and-shortcuts}

按 **F5**、选择「视图 → 设置」或在视频区右键选择「设置」。

切到「播放与记录 → 定位步长」，分别设置小步、中步和大步。每档接受 1–3600 的整数秒，默认分别为 5、30、60 秒。点击 **应用** 或 **确定** 后立即生效，并在下次启动时恢复。播放菜单、底栏提示、进度条和 **F1** 快捷键帮助会显示当前值。[查看默认键和定位操作](./playback.md#seek-controls)

优先音轨语言和优先字幕语言使用逗号分隔的语言代码，例如 `jpn,eng,zho`。下次打开媒体时按填写顺序选择，留空使用媒体默认轨道。

在「快捷键」页按分类、命令或按键筛选，选中一项，录制最多两个组合键，然后点击 **设置绑定**。遇到冲突时可确认替换。**清空此项** 取消该操作的绑定，**恢复此项** 恢复默认键。**F11**、观看时的 **Enter**、**Esc**、**Tab** 和系统保留键受保护。列表获得焦点时，按 **Enter** 默认播放选中项。

## 应用与恢复默认

**应用** 保存本次修改并保留设置窗口，**确定** 保存并关闭，**取消** 丢弃尚未应用的修改。设置无法写入时会提示，当前设置继续生效。

| 按钮 | 作用 |
| --- | --- |
| **恢复本页默认** | 恢复当前页的草稿。「播放与记录」页重置定位步长、截图目录、语言偏好、历史开关和断点策略。「快捷键」页重置各操作的默认键。「跳略播放」页将三个开关关闭并将秒数归零。 |
| **恢复全部设置** | 确认后重置播放偏好、取景、窗口布局和快捷键，保留已记录的历史、媒体文件和截图。 |

两种恢复操作都在点击 **应用** 或 **确定** 后生效。

## 最近文件与断点续播 {#resume-playback}

播放历史默认关闭。在设置中勾选「记录最近文件和播放进度」后，最多保存 50 项，可从「文件 → 最近文件」查看最近 10 项。文件不存在时，菜单项会变灰。文件大小或修改时间变化时，从头播放。

当上次播放位置超过 30 秒且距离结尾超过 30 秒时，默认先暂停在首帧并询问。选择「继续」会恢复原断点。「从头播放」、直接按播放或等待 8 秒会使用本次片头设置，未启用时从 0 秒播放。主动定位会使用指定时间。也可以在设置中选择总是继续或始终从头。停止保留已存断点，本会话再次按播放会使用片头设置。自然结束和自动跳过片尾均会清除本项断点。[跳略播放](./playback.md#skip-playback)

播放进度每 5 秒合并保存，暂停、切片和退出时补存。关闭记录后保留已有记录。在设置中点击 **立即清除最近文件和进度** 会马上清除历史。再次主动打开文件时，可重新记录该文件。

## 自动记忆的偏好 {#remembered-preferences}

倍速、保持音调、字幕显隐、字幕字体比例、音频延迟和字幕延迟在换片及重启后继续生效。音量、静音和鼠标模式也会保存。[音轨、字幕与倍速的操作](./media.md)

循环模式和随机开关会在下次启动时恢复。随机播放的回退记录随会话结束。[循环与随机播放](./playlist.md)

跳略总开关、片头片尾开关和两个秒数也会随偏好恢复。可关闭总开关来临时停用跳略并保留数值。[跳略播放](./playback.md#skip-playback)

主窗口的位置、大小、最大化和置顶状态会自动保存。列表会记住停靠或独立状态、显隐、停靠宽度和独立窗口的位置与大小。启动时恢复普通或最大化窗口，队列内容按本次会话管理。

取景倍率和画面中心会保留到下一段视频及下次启动。按 **R** 保存 1× 居中的取景。[缩放和取景](./zoom-and-pan.md)

关闭或清除历史时，这些偏好和设置里已应用的修改继续保留。便携版也将它们保存在当前 Windows 用户的配置目录中。[配置与历史文件](../development/reference.md#settings-files)
