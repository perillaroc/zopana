# 截图与设置

## 保存截图与查看媒体信息

| 操作 | 结果 |
| --- | --- |
| **Ctrl+S** | 保存无字幕的原始画面。 |
| **Ctrl+Shift+S** | 保存包含字幕和黑边的当前取景，排除应用 OSD。 |
| **I** | 打开媒体信息，查看分辨率等实际信息，也可通过「视图 → 媒体信息」打开。 |
| **T** | 切换主窗口置顶。 |

截图在后台写入系统图片目录的 `zopana` 子目录，格式为 PNG，文件名自动避开已有文件。保存成功后会显示路径和「打开文件夹」。按 **F5** 打开设置可更改保存目录。

## 设置语言偏好和快捷键

按 **F5** 或选择「视图 → 设置」。音轨和字幕语言偏好使用逗号分隔的语言代码，例如 `jpn,eng,zho`，在下次打开媒体时生效。

在快捷键页可按分类筛选，为每项操作录制最多两个单组合键，发生冲突时可确认替换。可以恢复单项或全部默认值。点击 **应用** 或 **确定** 更新快捷键、帮助和提示，**取消** 会丢弃未应用的修改。**F11/Enter** 全屏、**Esc**、**Tab** 和系统保留键保持保护。

## 最近文件与断点续播

播放历史默认关闭。在设置中勾选「记录最近文件和播放进度」后，最多保存 50 项，可从「文件 → 最近文件」查看最近 10 项。文件不存在时，菜单项会变灰。文件大小或修改时间变化时，从头播放。

当上次播放位置超过 30 秒且距离结尾超过 30 秒时，默认先暂停在首帧并提示继续或从头播放。可以在 8 秒内选择、主动播放或定位，超时则从头播放。也可以在设置中选择总是继续或始终从头。停止保留已存断点，本会话再次按播放则从 0 开始。自然播放完毕会清除该断点。

播放进度每 5 秒合并保存，暂停、切片和退出时补存。关闭记录后，已有记录仍可保留。「清除最近文件和进度」立即生效，取消设置窗口后仍然有效。再次主动打开文件时，可重新记录该文件。

## 窗口和播放偏好

主窗口的位置、大小、最大化和置顶状态，以及列表的位置、停靠或浮动形态、显隐和宽度会自动保存。启动时恢复普通或最大化状态，队列内容按本次会话管理。音量、静音、鼠标模式、倍速、音调保持、字幕显隐、字幕字体比例、音频和字幕延迟以及取景都会记住，关闭或清除历史时仍会保留。便携版的设置和历史也保存在 Windows 用户目录中，见[配置与历史文件](../development/reference.md#settings-files)。
