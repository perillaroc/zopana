# 音轨、字幕与进阶播放

## 切换音轨和字幕

音频和字幕菜单按当前文件显示实际轨道的语言、名称及内封或外挂信息。按 **J** 切换音轨，按 **H** 显示或隐藏字幕，按 **K** 切换字幕轨。

按 **Ctrl+L** 手动加载 SRT、ASS、SSA 或 VTT，也可以把字幕拖到已加载的视频上。视频和字幕混合拖入时，仅关联与第一个媒体文件同名的字幕。同目录可自动匹配同基名或语言后缀字幕，例如 `movie.srt`、`movie.en.ass`、`movie.zh-Hans.vtt`。

字幕随画面缩放，放大时可能裁切，可按 **R** 恢复适窗。字幕菜单提供 0.5–2.0× 字体大小和字幕延迟，音频菜单提供音频延迟。正延迟表示较晚播放或显示，换片时音频和字幕延迟归零。

## 调整倍速与逐帧观察

在视频区按 **[** 或 **]**，每次调整 0.25×，按 **Backspace** 恢复 1×。播放菜单提供 0.5/0.75/1/1.25/1.5/2/3× 及音调保持。倍速在本次会话换片后延续，重启后回到 1×。缩放或倍速偏离 1× 时，顶栏显示对应数值。

按 **D** 暂停并向前一帧。按 **A** 和 **B** 设置至少相隔 0.5 秒的区间循环。按 **Ctrl+B** 或定位到区间外可清除循环。
