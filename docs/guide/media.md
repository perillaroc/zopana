# 音轨、字幕与进阶播放

## 切换音轨和字幕

音频和字幕菜单按当前文件显示实际轨道的语言、名称及内封或外挂信息。按 **J** 切换音轨，按 **H** 显示或隐藏字幕，按 **K** 切换字幕轨。

手动选择的轨道只作用于当前文件；打开下一段时，播放器按[语言偏好](./settings.md#seek-and-shortcuts)选择新文件中的轨道。

按 **Ctrl+L** 手动加载 SRT、ASS、SSA 或 VTT，也可以把字幕拖到已加载的视频上。视频和字幕混合拖入时，仅关联与第一个媒体文件同名的字幕。同目录可自动匹配同基名或语言后缀字幕，例如 `movie.srt`、`movie.en.ass`、`movie.zh-Hans.vtt`。

字幕随画面缩放，放大时可能裁切，可按 **R** 恢复适窗。字幕菜单提供 0.5–2.0× 字体比例，当前值会随字幕显隐一起保存。

音频和字幕菜单分别提供延迟设置，范围均为 −3600 至 3600 秒，默认 0。正值让对应的音频或字幕更晚出现。两种延迟都会在换片和重启后继续使用，可从各自的菜单归零。

## 调整倍速与逐帧观察

在视频区按 **[** 或 **]**，每次调整 0.25×，范围 0.25×–3×。按 **Backspace** 恢复 1×。在「播放 → 倍速」中可选预设速度和「保持音调」，默认 1× 并开启保持音调。换片和重启都会保留这两项偏好。缩放或倍速偏离 1× 时，顶栏显示对应数值。

按 **D** 暂停并向前一帧。要查看上一帧，在主窗「播放」菜单或控制窗口的「播放」页选择「后退一帧」。播放中会先暂停，再回到上一帧并停住。到达首帧后，画面会停在首帧。可在「设置 → 快捷键」为观看区绑定按键，每按一次后退一帧。

按 **A** 和 **B** 设置至少相隔 0.5 秒的区间循环。按 **Ctrl+B** 或定位到区间外可清除循环。
