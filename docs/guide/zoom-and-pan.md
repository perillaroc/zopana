# 缩放拖动与鼠标模式

首次启动时选中 **缩放拖动**。用顶栏的模式按钮或在视频区按 **V** 切换到 **常规播放**。

| 视频区操作 | 缩放拖动 | 常规播放 |
| --- | --- | --- |
| 垂直滚轮 | 指向细节上滚放大、下滚缩小。每格约 15%，范围 1×–8×。指向黑边时取最近的画面边缘。 | 上滚增大音量、下滚减小音量。每格 5 个百分点，范围 0–100%，细刻度按比例累计。 |
| 左键单击 | 保持当前播放状态。 | 松开后等待系统双击间隔，确认是单击后切换一次播放或暂停。 |
| 按住左键拖动 | 移动画面，到边界停住。松手或失焦即结束拖动。 | 超过系统拖动距离后取消这次单击，画面保持原位。 |
| 双击 | 切换全屏。 | 切换全屏，保留播放状态。 |
| Ctrl+滚轮 | 以指针为锚点缩放。 | 以指针为锚点缩放，保留常规播放模式。 |

## 放大和恢复适窗

在视频区按 **+** 或 **−**（含数字小键盘）可按画面中心缩放。点击 **恢复适窗** 或在视频区按 **R** 回到 1× 居中。

切换模式时，当前手势结束，保留当时可见的构图、音量和播放状态。调整窗口大小或切换全屏时，播放器会沿用倍率和取景中心，并根据画面边界限制可见范围。同一次运行中，换片默认沿用取景，可在「画面与窗口」中选择打开新文件时恢复适窗。重启后从 1× 居中适窗开始，播放时按 **R** 也可恢复适窗。[画面与窗口设置](./settings.md#video-and-window)

## 用控制窗口取景 {#control-window-framing}

按 **F7** 打开[控制窗口](./playback.md#control-window)，切到 **缩放与平移**。可以在 **缩放拖动** 和 **常规播放** 两种模式下使用。

1. 暂停在要观察的帧。在「取景」内用滑杆从 1× 放大到 4×。也可点滑杆旁的缩放图标，每档约 15%，或在拖动区滚动滚轮。倍率范围为 1×–8×，缩放以主视频区中心为锚点。
2. 在同一拖动区按住左键平移，也可点箭头微移，按住箭头可以连续移动。箭头始终沿屏幕方向移动画面。到达边界时，对应方向停住，反向可立即移动。
3. 点四个箭头中间的 **画面居中**，画面回到中央并保留 4×。点倍率右侧的 **恢复适窗** 图标则回到 1× 居中。两项操作都保留当前暂停帧和额外旋转角度。

在主视频区缩放、拖动或调整窗口后，小窗会同步实际倍率及可移动的方向。松手、失焦、隐藏或换片会结束正在进行的平移。

### 按住看全图 {#hold-full-view}

在 **缩放与平移** 页，按住拖动区下方的 **按住看全图**，即可按当前角度查看 1× 居中的完整画面。松开后回到原来的倍率和内容位置。播放中影片继续播放，暂停时一直停在同一帧。

也可在「设置 → 快捷键」搜索 **按住看全图**，录制组合键，点 **设置绑定** 后应用。默认未绑定。焦点回到观看区后，按住自定义键查看全图，松开即可返回。**R** 仍可直接恢复适窗。

核对细节位置时，可以先暂停，按 **Alt+K** 顺时针转 90°，放大到 8×，再把细节移到画面一侧。按住看全图可以确认它在完整画面中的位置，松开后继续观察原处。失焦、收起小窗或切换到播放页会结束预览。预览中执行取景调整会先恢复原取景，再执行该操作。换片沿用预览前的取景，或按「打开新文件时恢复适窗取景」的设置回到 1×。

### 固定参考帧对照 {#reference-frame}

1. 暂停在动作开始处，调整取景。在 **F7 → 缩放与平移 → 参考帧** 点击图钉（**固定当前帧**）。
2. 用左侧的逐帧图标前进或后退一帧。点眼睛图标在参考帧和当前画面之间切换，画面提示会显示参考帧的时间。主窗的「画面」菜单也提供固定、切换和清除。
3. 再次固定会用播放器此刻的画面替换参考帧。点带斜线的图钉（**清除参考帧**）回到实时画面。参考帧只在本次运行中保留。

切换显示时，播放器沿用原来的播放或暂停状态，保留「撤销上次定位」记录。逐帧、定位或按住看全图时会先切回实时画面。松开后如果恢复到原取景，仍可查看参考帧。调整倍率、位置、角度或视频区大小后请重新固定。

**复制当前取景** 和 **当前取景截图** 取正在查看的图像。保存参考帧时，文件名使用参考帧的时间。**完整画面截图** 仍取播放器此刻的完整画面。

## 旋转画面 {#video-rotation}

在「画面 → 额外旋转」或视频右键菜单可顺时针、逆时针旋转或复位。观看时 **Alt+K** 顺时针转 90°，**Alt+Shift+K** 逆时针转 90°，**Alt+Ctrl+K** 将额外角度设为 0°。额外角度是在文件自带方向上继续旋转的角度，菜单和提示均显示该角度。

旋转时保持取景倍率和所关注的内容点，画面边界可能限制取景位置。**R** 只把取景恢复到 1× 居中，旋转复位只改角度。字幕随画面缩放，放大取景时可能裁切。角度会跨文件、跨重启保留，也可在播放前预设。[画面与窗口设置](./settings.md#video-and-window)
