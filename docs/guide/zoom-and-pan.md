# 缩放拖动与鼠标模式

首次启动时选中 **缩放拖动**。用顶栏的模式按钮或在视频区按 **V** 切换到 **常规播放**。

| 视频区操作 | 缩放拖动 | 常规播放 |
| --- | --- | --- |
| 垂直滚轮 | 指向细节上滚放大、下滚缩小。每格约 15%，范围 1×–8×。指向黑边时取最近的画面边缘。 | 上滚增大音量、下滚减小音量。每格 5 个百分点，范围 0–100%，细刻度按比例累计。 |
| 左键单击 | 保持当前播放状态。 | 松开后等待系统双击间隔，确认是单击后切换一次播放或暂停。 |
| 按住左键拖动 | 移动画面，到边界停住。松手或失焦即结束拖动。 | 超过系统拖动距离后取消这次单击，画面保持原位。 |
| 双击 | 切换全屏。 | 切换全屏，保留播放状态。 |
| Ctrl+滚轮 | 以指针为锚点缩放。 | 以指针为锚点缩放，保留常规播放模式。 |

## 放大和恢复适窗

在视频区按 **+** 或 **−**（含数字小键盘）可按画面中心缩放。点击 **恢复适窗** 或在视频区按 **R** 回到 1× 居中。

切换模式时，当前手势结束，保留当时可见的构图、音量和播放状态。调整窗口大小或切换全屏时，播放器会沿用倍率和取景中心，并根据画面边界限制可见范围。同一次运行中，换片默认沿用取景，可在「画面与窗口」中选择打开新文件时恢复适窗。重启后从 1× 居中适窗开始，播放时按 **R** 也可恢复适窗。[画面与窗口设置](./settings.md#video-and-window)

## 用控制窗口取景 {#control-window-framing}

按 **F7** 打开[控制窗口](./playback.md#control-window)，切到 **缩放与平移**。可以在 **缩放拖动** 和 **常规播放** 两种模式下使用。

1. 用小窗顶部的 **暂停** 停在要观察的帧。从 1× 把滑杆调到 4×。滑杆范围为 1×–8×，也可以点 **−** 和 **＋** 调节，每档约 15%。缩放以主视频区中心为锚点。
2. 用箭头微移画面，按住箭头可以连续移动。也可在平移区按住左键拖动，把目标移到中央。箭头始终按屏幕方向移动画面，旋转后也一样。到达边界时，对应方向停住，反向可立即移动。
3. 点 **画面居中**，画面回到中央并保留 4×。再点 **恢复适窗**，回到 1× 居中。这两项操作保留同一暂停帧和额外旋转角度。

在主视频区缩放、拖动或调整窗口后，小窗会同步实际倍率及可移动的方向。松手、失焦、隐藏或换片会结束正在进行的平移。

## 旋转画面 {#video-rotation}

在「画面 → 额外旋转」或视频右键菜单可顺时针、逆时针旋转或复位。观看时 **Alt+K** 顺时针转 90°，**Alt+Shift+K** 逆时针转 90°，**Alt+Ctrl+K** 将额外角度设为 0°。额外角度是在文件自带方向上继续旋转的角度，菜单和提示均显示该角度。

旋转时保持取景倍率和所关注的内容点，画面边界可能限制取景位置。**R** 只把取景恢复到 1× 居中，旋转复位只改角度。字幕随画面缩放，放大取景时可能裁切。角度会跨文件、跨重启保留，也可在播放前预设。[画面与窗口设置](./settings.md#video-and-window)
