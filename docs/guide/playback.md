# 播放与窗口

打开文件后自动播放，顶栏显示文件名。底栏第一行是播放进度和音量，第二行从左到右是播放或暂停、停止、后退、前进、打开文件和时间，播放列表按钮在最右侧。窄窗口会缩短音量滑块，保留常用按钮。

## 播放与定位 {#seek-controls}

| 操作 | 使用方法 |
| --- | --- |
| 暂停、继续 | 点击 **暂停** 或 **播放**，也可在视频区按 **Space**。 |
| 停止、重播 | 点击停止或在视频区按 **S**。停止会保留文件，再按 **Space** 按当前片头设置重新播放。 |
| 拖动进度条 | 拖动时预览 `HH:MM:SS` 格式的目标时间，松手后定位。暂停时也可以查看目标帧。 |
| 小步、中步、大步 | 视频区和聚焦的进度条共用三档步长。**←/→** 默认后退或前进 5 秒，**Shift+←/→** 默认 30 秒，**Ctrl+←/→** 默认 60 秒。 |
| 跳到首尾或指定时间 | **Home** 跳到开头，**End** 跳到最后一个可定位位置。**Ctrl+G** 打开跳转时间窗口。 |
| **PageUp / PageDown** | 进度条获得焦点时，分别前进和后退 10 秒。在视频区，分别播放上一项和下一项。 |
| 底栏后退和前进按钮 | 左键按小步定位。右键在有相邻项可切换时播放上一项或下一项。 |
| 调节音量、静音 | 拖动音量滑块或在视频区按 **↑/↓**，范围 0–100%。按 **M** 或点击扬声器切换静音。静音时调音量会取消静音。无音轨时音量控件禁用。 |
| 换片、重试 | 播放期间或显示「播放完毕」时，可以用 **Ctrl+O** 打开下一段。文件损坏时，可以查看错误提示并在同一窗口重新选片。 |

长按三档定位键会连续调整目标，目标限制在媒体的可定位范围内。暂停时定位后仍保持暂停。媒体加载完成且有可定位范围时，进度条和定位命令可用。

按 **F5** 打开[设置](./settings.md#seek-and-shortcuts)可以修改步长。按 **F1** 查看当前步长和快捷键。用 **Tab** 或 **Shift+Tab** 在控件间切换焦点。音量滑块聚焦时，方向键调音量。按钮聚焦时，按 **Space** 激活按钮。

## 跳略播放 {#skip-playback}

在「播放 → 跳略播放」中打开总开关，再分别勾选「跳过片头」和「跳过片尾」。子菜单会显示已设秒数。在视频区按 **Shift+'** 切换总开关，按 **'** 打开「跳略设置」。视频和纯音频都可使用，进度条始终显示完整时长。

每段可设为 0–86400 整数秒，0 秒时播放该段。新开文件或重播时从设定的片头位置开始。自然播放到片尾边界时，播放器按当前循环与随机策略处理下一项；关闭随机时遵循当前列表顺序。过短的文件会完整播放并提示一次。时长迟到时仍可根据实际进度判断片尾。秒数和子开关的修改从下次打开或重播起生效，关闭总开关立即生效。[循环与随机播放](./playlist.md#playback-order)

选择「继续」时从有效断点播放。在片尾区恢复时可以继续看完该段。按 **Home** 可以回看片头，手动定位到片尾也可以继续播放，定位回正文后可再次自动跳过片尾。暂停、逐帧、进度条预览和有效的 A–B 循环期间，播放器会暂缓片尾判断。在片尾区清除 A–B 时会继续播放当前项。[断点设置](./settings.md#resume-playback) · [A–B 循环](./media.md)

## 移动窗口与全屏 {#window-and-fullscreen}

在「视图 → 窗口大小」或视频右键菜单中选择 50%、100%、150%、200% 或「适合工作区」。观看时可按 **1–5**，也可使用 NumLock 开启的小键盘。100% 让画面使用与视频有效显示尺寸相同的物理像素数。窗口会加上控件、边框和停靠列表的空间，并遵守屏幕工作区与最小窗口尺寸。受限时会显示请求和实际比例。

在全屏或最大化时选择比例，会回到普通窗口并应用所选尺寸。所选策略会用于接下来打开的视频，手动拖动窗口边缘后改为沿用普通窗口大小。比例按完整视频计算，原有取景倍率、关注点和播放状态继续生效。纯音频时比例命令不可用。[窗口大小偏好](./settings.md#video-and-window)

顶部工具条左侧打开主菜单，右侧提供全屏、最小化、最大化或还原、关闭。拖动工具条空白处可移动窗口，双击该区域可切换最大化。

双击画面、按 **F11** 或在视频区按 **Enter**（含数字小键盘）可切换全屏。全屏顶栏和底栏覆盖在画面上，闲置 2.5 秒后隐藏。将鼠标移到对应边缘或使用键盘即可唤出控件。

按 **Esc** 会先取消拖动或关闭已打开的菜单、播放列表覆盖面板。全屏中没有这些操作时，按 **Esc** 会退出全屏并恢复进入前的窗口状态。
