# 文件与播放列表

## 从资源管理器或命令行打开 {#launch-media}

在资源管理器中右键点击媒体文件，选择 **打开方式 → 选择其他应用**，浏览到解压后的 `zopana.exe`。也可以把一个或多个媒体文件拖到 `zopana.exe` 上启动。多个有效文件按传入顺序加入播放列表，并从首项播放。

在 PowerShell 中可以传入一个或多个文件路径。相对路径以当前工作目录为准，带空格的路径用引号括起。

```powershell
& 'C:\Tools\zopana\zopana.exe' 'D:\影片\示例 01.m2ts'

Set-Location 'D:\影片'
& 'C:\Tools\zopana\zopana.exe' '.\示例 01.m2ts' '.\示例 01.srt' '.\示例 02.opus'
```

## 打开和追加文件

| 操作 | 播放列表的变化 |
| --- | --- |
| 点击 **打开文件** 或按 **Ctrl+O** | 支持多选，替换列表并播放第一项。 |
| 按 **Ctrl+Shift+O** 添加文件 | 追加到列表，保持正在播放的内容。 |
| 拖入视频区 | 默认替换列表，按住 **Ctrl** 时追加。 |
| 拖入播放列表 | 追加文件，或放入插入线所示的位置。 |
| 选择 **添加文件夹** | 在后台扫描一层目录，按自然文件名排序并去重，可取消扫描。 |

「打开文件」和「添加媒体文件」的默认筛选均包含 M2TS、WMV 和 Opus。一起导入媒体和字幕时，同名字幕会附到首个实际加入的媒体。播放时也可以把字幕单独拖入窗口。

## 显示和移动列表

按 **P** 或点击列表按钮切换播放列表的显隐。宽窗口中可拖动分隔条调整停靠列表宽度。窄窗口和全屏使用视频区的覆盖面板。

点击列表标题区的 **独立窗口**，可以把列表移到浮动窗口，单独移动和调整大小。它与主窗口共用一个任务栏项目。主窗口最小化和恢复时，已展开的浮动列表随之隐藏和显示。点击浮动列表的关闭按钮或在列表中按 **Ctrl+W** 可收起列表。

## 切换、移除和移动项目

在列表中按 **Enter** 或双击以播放所选项，按 **Delete** 移除，按 **Ctrl+↑/↓** 重排。只选择、添加或重排会保留当前播放项和状态。移除当前项会停止播放并选中相邻项，可以手动播放该项。

在视频区按 **PageUp/PageDown** 可切到上一项或下一项。底栏后退和前进按钮也可用右键切换相邻项。

## 排序、反转和打乱 {#sort-playlist}

点击列表上的 **排序**，或打开「播放 → 列表排序」与列表右键菜单中的同名入口。先选升序或降序，再选字段：

| 字段 | 比较方式 |
| --- | --- |
| 文件名、媒体标题 | 按自然数字顺序比较，例如第 2 集在第 10 集之前；文件名不区分大小写，缺少媒体标题时用文件名。 |
| 扩展名、所在文件夹、完整路径 | 按扩展名或所在目录分组，组内比较文件名；也可直接比较完整路径。 |
| 文件大小、修改时间、创建时间 | 按字节数或实际时间比较。 |
| 时长、分辨率 | 按秒数或编码像素面积比较；面积相同再比较宽、高。纯音频没有分辨率。 |
| 添加顺序 | 按本次会话的加入先后顺序排列。 |

相同值保持原先的相对顺序，未知值在升序和降序中都排在最后。**反转当前顺序**直接倒置所有行；**随机打乱列表**只洗牌一次。打乱不切换「随机播放」，也不改变其回退记录。三种操作都保留正在播放的项目和选中项；随机播放关闭时，「下一项」遵循新的列表顺序。

标题、时长和分辨率可从尚未播放的文件读取。列表显示读取进度，可点 **取消排序** 保留当前顺序。将鼠标停在项目上可以查看已取得的元数据。同名文件的大小或修改时间变化后，再次排序时会重新读取。

列表只在发出排序命令时重排。追加、插入或手动拖动后仍保留指定位置，可点 **按上次条件重新排序**。上次选择的字段和方向会保存，启动时不会恢复上次的列表内容。排序命令默认没有快捷键，可在设置中为它们绑定。

## 循环与随机播放 {#playback-order}

在「播放 → 循环模式」选择循环方式，或在视频区按 **Ctrl+R** 依次切换。用「播放 → 随机播放」或 **Ctrl+Shift+R** 单独开关随机。默认不循环，随机关闭。

列表工具区显示当前循环模式和随机开关。点击循环按钮依次切换三档，点击「随机播放」切换开关。也可右键点击列表，直接选择循环模式或开关随机。停靠、覆盖和独立列表均可使用这些操作，空列表也可预先选择。

| 循环模式 | 随机关闭 | 随机开启 |
| --- | --- | --- |
| 不循环 | 按列表顺序播到末尾后停止。 | 播完本轮各项后停止。 |
| 单个循环 | 自动重播当前项。 | 自动重播当前项，手动下一项按随机顺序前进。 |
| 全部循环 | 播到末尾后回到首项。 | 播完本轮后开启下一轮，多项时两轮交界会切换到另一项。 |

手动切换可以离开正在单个循环的项目。只有全部循环可在末尾开启新一轮。随机开启时，「上一项」按本次会话的播放记录返回，随后按「下一项」可沿原记录前进。回退记录最多保留 1,024 条，自动跳过的坏文件可在列表中手动重试。只改变循环模式会保留这份记录。关闭再开启随机时，以当前项开始新一轮。添加的项目可参加本轮，删除的项目会从随机候选和回退记录中移除。

自动续播会跳过本次推进中已打开失败的项目，尝试次数最多为推进开始时的列表项数。单个循环重播失败时停在当前项，可点击「重试」。

循环模式和随机开关会自动保存，下次启动时即使列表为空也能恢复。关闭或清除播放历史时，仍会保留这两项设置。

之前为「随机播放」设置的快捷键仍会同时开启全部循环和随机。可在设置的快捷键页找到「旧版随机播放」，或为新的随机开关分配快捷键。按 **F1** 查看当前绑定。
